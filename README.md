# Music Player App

A simple music player I'm making to learn **C++**, **SFML**, and **ImGui**.

I started this project as a way to get more comfortable with C++ while also learning how to work with external libraries and build a desktop application.

The goal is to eventually have a simple music player where I can load and play music through a custom interface.

## Built With

* C++
* SFML
* ImGui
* CMake

## Current Features

The project is still a work in progress. Some of the things I'm working on include:

* Music player controls
* User interface with ImGui
* Audio handling with SFML

## Why I Made This

I wanted to start learning C++ by making something that I would actually use.

Instead of following a basic tutorial project, I decided to try making a music player and figure out how different parts of a C++ application fit together.

This project has also given me a chance to learn more about:

* C++ project structure
* CMake
* Working with external libraries
* GUI programming
* Audio programming
* Debugging and managing a larger codebase

## Status

**Work in progress**

This project is mainly being used as a learning project, so things are likely to change as I learn more about C++ and the libraries I'm using.
